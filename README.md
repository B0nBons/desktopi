### Welcome to DesktoPI !!!

My main motivations towards making this was time management. I tend to struggle with setting aside actual time to do things I need to do, or play games instead of doing homework. That is why, I (tried) to make DesktoPI!!

The main features I wanted to make was a pomodoro timer, since taking breaks makes working much easier, some sort of todo list to give the satisfaction of checking things off, and a music player (I wanted to make one that could avoid ads)! Then halfway into my roject, I realised I was making features that were honestly, kind of useless to me. I don't need my computer to tell me the weather- thats why Windows exist (so punny). As of now, I've decided to focus on having a functioning Pomodoro timer, music player, and todo list. And also to make sure a feature has logical sense before I start coding it. Oops.

This project should be able to run on nearly all Operating Systems!      
 
 

To install, download this as a .zip file, and run the following:
```
cd /focus_buddy/
python -m pip install pyinstaller
python -m PyInstaller --onefile --windowed --name DesktoPI main.py
```
